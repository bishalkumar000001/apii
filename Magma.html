Frequently asked questions

Where do I get an API key?

Create an account at /account, then create a key in the API keys panel. Copy it immediately because the full key is shown only once.

How does manual payment work?

Pay using the details displayed in your account, submit your transaction reference, and wait for the owner to verify and approve it.

How do I protect my key?

Keep keys on your server, use the X-API-Key header, and revoke any key that may have been exposed. Do not place secrets in public client-side code.

Where can I check API usage?

Sign in to the account dashboard and open Usage & examples to review recent authenticated requests and billing mode.
